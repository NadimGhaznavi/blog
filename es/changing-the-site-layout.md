Decidí que ya no me gustaba cómo se veía la página principal del blog. Alojo el sitio en GitHub y uso una versión modificada del tema jekyll/minima. Mi versión se llama [minimo](https://github.com/nadimghaznavi/minimo). Modifiqué `_layouts/home.html` para mostrar las publicaciones en una tabla. ¡Espero que les guste el nuevo aspecto!
