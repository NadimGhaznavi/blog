**AI Snake Lab** — інтерактивне середовище для експериментів із навчанням із підкріпленням, у якому ШІ-агенти вчаться грати в класичну «Змійку». Воно має живий термінальний інтерфейс на Textual (TUI), гнучку базу даних пам’яті повторного відтворення досвіду та модульні визначення моделей.

![AI Snake Lab](/images/2025-10-16-ai-snake-lab.png)

---

# 🚀 Можливості

- 🐍 **Класичне середовище «Змійки»** з настроюваними розмірами поля та правилами
- 🧠 **Інтерфейс ШІ-агента**, який підтримує кілька архітектур (лінійна модель, RNN, CNN)
- 🎮 **Симулятор на основі Textual** із візуалізацією та метриками в реальному часі
- 💾 **Пам’ять повторного відтворення на SQLite** для зберігання кадрів, епізодів та запусків
- 🧩 **Облік метаданих експериментів**: моделі, гіперпараметри, версії відображення стану
- 📊 **Вбудовані графіки** хешрейту, результатів гри та прогресу навчання

# 🔄 Динамічне навчання

Прапорець *Dynamic Training* («Динамічне навчання») поступово збільшує обсяг *тривалого навчання*, яке виконується наприкінці кожної *епохи*. Із зростанням загальної кількості епох код `AIAgent:train_long_memory()` виконується наприкінці кожної епохи дедалі більше разів, але не більше ніж `MAX_ADAPTIVE_TRAINING_LOOPS`. Зараз граничне значення — `16`, як показано в розрахунку нижче:

```
    if self.dynamic_training():
        loops = max(
            1, min(self.epoch() // 250, DAIAgent.MAX_DYNAMIC_TRAINING_LOOPS)
        )
    else:
        loops = 1

    while loops > 0:
        loops -= 1
        self.train_long_memory()
```

# 🧩 Epsilon N

Клас *Epsilon N*, натхненний статтею Річарда Саттона [The Bitter Lesson](http://www.incompleteideas.net/IncIdeas/BitterLesson.html), може безпосередньо замінити традиційний алгоритм *Epsilon Greedy*. Він створює окремий екземпляр звичайного *Epsilon Greedy* для кожного рахунку. Наприклад, коли ШІ набрав 7 очок, використовується екземпляр за адресою `self._epsilons[7]`.

На знімку нижче показано графік *найкращих результатів* за традиційного алгоритму *Epsilon Greedy* з єдиним екземпляром і ввімкненим [динамічним навчанням](#динамічне-навчання). Такий алгоритм швидко збігається, але прогрес нерівномірний. Різкі стрибки на лінії рекордів означають, що дослідження варіантів зменшується раніше, ніж ШІ встигає повністю опанувати кожний етап гри.

![Традиційний Epsilon Greedy](/images/2025-10-16-highscores-epsilon.png)

На наступному знімку показано найкращі результати з вимкненим [динамічним навчанням](#динамічне-навчання) та алгоритмом *Epsilon N*. Окреме значення epsilon для кожного рівня рахунку дозволяє підтримувати дослідження локально. Внаслідок цього крива рекордів виходить плавнішою та ближчою до лінійної: ШІ закріплює навички на кожному етапі, перш ніж переходити до наступного.

![Epsilon N](/images/2025-10-16-highscores-epsilon-n.png)

Як видно вище, традиційний Epsilon Greedy забезпечує повільніше вдосконалення: крива рекордів досить рано вирівнюється. Натомість Epsilon N підтримує сталий прогрес, поки ШІ окремо опановує кожен рівень рахунку.

# 💻 Встановлення

Проєкт опублікований на [PyPI](https://pypi.org/project/ai-snake-lab/). Ви можете встановити *AI Snake Lab* через `pip`.

## Створення віртуального середовища

```shell
python3 -m venv snake_venv
. snake_venv/bin/activate
```

## Встановлення AI Snake Lab

Після активації середовища *venv*:

```shell
pip install ai-snake-lab
```

# ⚠️ Обмеження

Оскільки симуляція працює всередині Textual TUI, зміна розмірів термінала й перемальовування графіків можуть трохи впливати на її швидкість. Тому найкращі результати можуть з’являтися під дещо іншими номерами ігор у різних запусках. Це очікувана поведінка, а не помилка в логіці ШІ.

Якщо вам потрібні повністю відтворювані симуляції, напишіть мені: я можу реалізувати **безінтерфейсний режим**, у якому симуляція працюватиме в окремому процесі поза Textual.
